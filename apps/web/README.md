# apps/web

Next.js (App Router) application — UI + API route handlers for the PC Builder
Platform. Scaffolded with `create-next-app` (TypeScript, Tailwind CSS v4, ESLint).

Part of the `pc-builder-platform` pnpm workspace — run all commands from the repo
root (`pnpm dev`, `pnpm build`, etc.), which delegates to this package via Turborepo.

See `../../project-management/ARCHITECTURE.md` for the full architecture and
`../../project-management/DEVELOPMENT_ROADMAP.md` for what's implemented so far.
